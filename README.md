# Paul A. Skeffington — Public CV Export

This repository is the public-facing export target for a sanitized CV package generated from the private `CV` source repository.

## Public pull path

```bash
git clone https://github.com/pskeffington/CV-Public-Facing.git
cd CV-Public-Facing
ls documents/
```

## Repository contract

The public repository is an artifact surface, not the private working CV source tree. Public users should be able to pull this repository and retrieve only sanitized CV/report materials.

Expected generated structure:

```text
documents/
  Paul_A_Skeffington_Academic_CV_Public.pdf
  Paul_A_Skeffington_One_Page_Profile_Public.pdf
PUBLIC_MANIFEST.md
README.md
```

## Sanitization boundary

The private source repository remains the controlled workspace for master CV material, claim ledgers, evidence matrices, source extracts, and internal editing history. This repository should contain only public-safe compiled artifacts and public-safe explanatory metadata.

## Update source

Updates are generated by the private `CV` repository through its public export workflow. Manual edits in this repository may be overwritten by the next export.
