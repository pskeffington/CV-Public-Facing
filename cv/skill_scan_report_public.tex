\section*{Selected Skills Appendix}

This section summarizes selected skills that support current public-health, health-policy, and health-data-science work.

\subsection*{Research and Analytic Skills}

\begin{itemize}
    \item \textbf{R analytics:} Longitudinal research, statistical modeling, table generation, sample review, and manuscript-oriented analysis.
    \item \textbf{Python:} Data preparation, reproducible scripts, documentation support, and repeatable analytic workflows.
    \item \textbf{Health data science:} Dataset preparation, evidence organization, reproducible documentation, and transparent analytic outputs.
    \item \textbf{Reproducible research:} GitHub Actions, Makefile builds, LaTeX manuscripts, table exports, and structured project documentation.
    \item \textbf{Data governance:} Careful data handling, public/private separation, and conservative public communication of research status.
    \item \textbf{AI-assisted documentation:} Governed use of automation for drafting support, review, and quality-control assistance.
\end{itemize}

\subsection*{Developing Methods}

\begin{itemize}
    \item \textbf{Machine-learning evaluation:} Benchmark planning, model-card thinking, responsible evaluation notes, and early biomedical methods work.
    \item \textbf{Geospatial and environmental-health analysis:} WASH, terrain/access review, environmental screening, and rural health context.
\end{itemize}
